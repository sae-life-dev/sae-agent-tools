# new — завести задачу

Создаёт в папке задач `<NNN>_<имя>/` с ключом Jira — `<NNN>_<КЛЮЧ>_<имя>/`, а в ней
`задача.md` и пустой `правила-задачи.md`. Больше ничего.

## Порядок

1. Ключ Jira — значение после `--jira` в любом месте аргументов (`--jira ABC-123` или
   `--jira=ABC-123`). Убери из аргументов и `--jira`, и ключ. Название — всё, что осталось после
   `new`. Названия нет — спроси его выбором (ниже, «Вопрос о названии»).
2. Номер ставит скрипт. Если название начинается с номера — 1–3 цифры, за ними пробел, `_` или
   `-` (`024 …`, `024_…`, `24-…`), — не убирай его молча: скажи, что номер ставится сам, и спроси
   название без номера выбором. Четыре цифры и больше (`2024 отчёт`) — не номер, а часть названия.
3. Особые пробелы в названии сначала приведи к обычным: неразрывный, узкий и подобные замени
   обычным пробелом, пробелы нулевой ширины убери. Собери имя папки из названия: буквы в нижний
   регистр; пробелы — дефис, несколько подряд — один; дефисы по краям убрать; символы
   `/ \ : * ? " < > |` убрать. Имя вышло пустым — спроси другое название выбором. Ключ в имя не
   вставляй — его ставит скрипт. Название для заголовка `задача.md` — как написано (после замены
   пробелов).
4. Ключа нет (`--jira` не было, за ним ничего нет или `--jira` больше одного) — спроси выбором,
   по форме ключ в названии не ищи (`COVID-19` — часть названия, а не ключ). Если спрашиваешь и
   название, задай оба вопроса одним выбором: сначала название, потом ключ.
   - вопрос: «Ключ задачи в Jira? Ключ впиши в „Другое“»;
   - варианты: **«Без Jira»** — задача без ключа; **«Отмена»** — ничего не создавать;
   - ответ «Без Jira» — дальше без ключа; ключ во «Другом» — бери его; «Отмена» — скажи, что
     задача не заведена, и остановись. Ключ обычным сообщением не спрашивай. Без ответа ничего
     не делай.
5. Приведи ключ к виду `ABC-123`: пробелы по краям убери; латиницу подними в заглавные
   (`abc-123` → `ABC-123`); из ссылки на задачу возьми ключ (`…/browse/ABC-123` → `ABC-123`). Если
   ключ не виден однозначно — спроси, не угадывай. Остальное проверяет скрипт.
6. Запусти скрипт, каждый аргумент в одинарных кавычках (кавычку внутри — как `'\''`). С ключом
   ключ — третьим аргументом, без ключа третьего аргумента нет (пустой не передавай). Скрипт
   сам берёт папку задач из настроек проекта, выдаёт номер и пишет файл; сам папки не создавай
   и файлы не пиши.

   ```
   sh scripts/new.sh '<имя>' '<название>' '<КЛЮЧ>'
   sh scripts/new.sh '<имя>' '<название>'
   ```

7. Доложи по первой строке вывода. Где в таблице «спроси название» — спрашивай выбором, как
   ниже, и с ответом начни заново с шага 2 (ключ уже известен — его не переспрашивай):

| Вывод | Что сказать |
| --- | --- |
| `CREATED <папка>` | задача заведена: номер, путь к папке; с ключом — и ключ; дальше владелец пишет `задача.md` (с ключом — или `next` предложит заполнить его по Jira и КБ), а правила работы над задачей, если нужны, — в `правила-задачи.md`. Есть строки `jira.dup=<папка>` — предупреди: этот ключ уже есть у другой задачи, покажи каждую такую папку. Новую задачу не удаляй и не переименовывай |
| `NO_CONFIG <файл>` | папка задач для этого проекта не настроена; сначала `init` |
| `CONFIG_NO_KEY <файл> task.dir` | в настройках нет пути к папке задач; сначала `init` |
| `TASKS_MISSING <папка>` | в настройках указана папка, которой нет; `init` заново |
| `TASKS_UNMARKED <папка>` | папка из настроек не помечена как папка задач; `init` заново |
| `BAD_NAME <имя> number` | имя начинается с номера; спроси название без номера |
| `BAD_NAME …` | имя папки не подошло; покажи его и спроси другое название |
| `BAD_JIRA <ключ>` | ключ не похож на ключ Jira (вид `ABC-123`: латиница, дефис, номер); покажи его и спроси ключ выбором, как в шаге 4 |
| `NO_ARG` | не хватило аргументов; спроси название |
| любой другой | перескажи вывод как есть (вторая строка — системная ошибка) и скажи, что задача могла не создаться |

## Вопрос о названии

Название спрашивай выбором, не обычным сообщением:

- вопрос: «Название задачи? Название впиши в „Другое“»; если это повтор — коротко почему (номер
  в начале, имя не подошло);
- варианты: **«Ввести название»** — в описании: «впиши название в „Другое“»; **«Отмена»** —
  ничего не создавать;
- ответ: название во «Другом» — бери его как написано; «Ввести название» — задай этот же вопрос
  ещё раз; «Отмена» — скажи, что задача не заведена, и остановись. Название обычным сообщением
  не спрашивай. Без ответа ничего не делай.

## Чего не делать

- Не выбирать номер самому и не переименовывать существующие папки.
- Не создавать других файлов в задаче: остальное появляется на своих этапах.
- Не писать содержимое `задача.md` и `правила-задачи.md`: их пишет только владелец. Строку
  `**Jira:**` и заготовки пишет скрипт.
- Не ходить в Jira за названием или проверкой ключа.
