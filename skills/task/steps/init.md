# init — завести папку задач

Делает выбранную папку папкой задач (кладёт в неё `README.md` с меткой) и запоминает её в
настройках проекта `.claude/sae.local.md` (ключ `task.dir`) в рабочей папке сессии. Больше
ничего.

## Порядок

1. Путь — всё, что в аргументах после `init`. Это сама папка задач, имя любое.
2. Пути нет — спроси его выбором (инструмент вопроса с вариантами), в описании каждого варианта
   — полный путь от рабочей папки сессии:
   - `./задачи`
   - `./tasks`
   - `./work`

   Свой путь человек вводит в «Другое». Без ответа ничего не делай.
3. Запусти скрипт, путь — в одинарных кавычках (кавычку внутри — как `'\''`):

   ```
   sh ${CLAUDE_SKILL_DIR}/scripts/init.sh '<путь>'
   ```

   Скрипт сам раскрывает `~`, проверяет путь, создаёт папку и пишет настройки. Сам папки не
   создавай и файлы не пиши.
4. Доложи по первой строке вывода; следом идут строки `ключ=значение`:

| Вывод | Что сказать |
| --- | --- |
| `CREATED <папка>` | папка задач заведена |
| `MARKED <папка>` | папка была пустой, теперь это папка задач |
| `EXISTS <папка>` | папка задач здесь уже была, её не трогал |
| `CONFIG_DIFFERENT <файл>` | в настройках уже другая папка задач, ничего не менял; спроси выбором: **Оставить старую** — в описании путь `task.dir.old=` · **Заменить на новую** — в описании путь `task.dir=`. «Оставить старую» — скажи, что настройки прежние, и остановись. «Заменить на новую» — повтори с ключом: `sh ${CLAUDE_SKILL_DIR}/scripts/init.sh --replace-config '<путь>'` |
| `NOT_EMPTY <папка>` | папка не пустая и не помечена как папка задач, ничего не менял; покажи содержимое из вывода и спроси другой путь выбором, как в шаге 2, без варианта, полный путь которого — эта `<папка>`. Ответ — путь для шага 3; отказ в «Другое» — остановись |
| `NO_PARENT <папка>` | нет папки, в которой создавать; ничего не создано; попроси проверить путь |
| `NOT_DIR <путь>` | по пути лежит файл, а не папка; ничего не создано |
| `CONFIG_BAD <файл>` | файл настроек испорчен (`reason=`); ничего не менял; покажи файл и спроси, что делать |
| `CONFIG_FAILED <файл>` | папка готова (`folder=`), но настройки не записались; перескажи ошибку со второй строки |
| `NO_ARG` | путь не передан; спроси его выбором, как в шаге 2 |
| любой другой | перескажи вывод как есть и скажи, что папка могла не создаться |

После `CREATED`, `MARKED` и `EXISTS` назови путь к папке и что записано в настройках:

- `config=written` — путь записан; `config=replaced` — заменён (`task.dir.old=` → `task.dir=`);
  `config=same` — там уже был этот путь.
- `git=not-ignored` — подскажи добавить в `.gitignore` строку `.claude/*.local.md`: файл
  настроек личный. Сам `.gitignore` не трогай.
- `git=ignored`, `git=no-repo`, `git=no-git` — про git и `.gitignore` ничего не говори.

## Чего не делать

- Не создавать недостающие папки по пути: опечатка в пути не должна плодить папки.
- Не перезаписывать и не дополнять непустую папку и чужие файлы.
- Не трогать ничего, кроме выбранной папки и `.claude/sae.local.md`.
